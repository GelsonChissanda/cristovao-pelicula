# Cristóvão Películas

Website premium para a empresa automotiva Cristóvão Películas, criado com React, Vite, Tailwind CSS e Framer Motion.

## Recursos
- Navbar premium com efeito blur ao scroll
- Hero cinematográfico com iluminação vermelha e carro premium
- Sessão de serviços com cards modernos
- Galeria com modal de visualização
- Benefícios, promoção e seção sobre
- Contato com mapa integrado e botão WhatsApp flutuante
- Layout responsivo para celular, tablet e desktop

## Instalação

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```
